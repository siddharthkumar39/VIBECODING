# VIBECODING

## AI-Powered Invoice Intelligence Platform

VIBECODING is a full-stack AI application that extracts structured information from invoices using OCR and Large Language Models (Gemini API).

## Features

- Upload invoice images or PDFs
- OCR-based text extraction
- AI-powered invoice analysis
- Merchant, amount, GST and date extraction
- Responsive frontend
- REST API backend

## Tech Stack

- React.js
- FastAPI
- MongoDB
- Gemini API
- OCR
- Render
